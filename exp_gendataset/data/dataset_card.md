# Feature Stories

Matched contrastive stories for difference-in-means concept vectors, released with *From Stories to Features: Scaling Concept Vectors for AI Alignment & Interpretability*.

Each feature is a **concept–antagonist pair**, not a concept label alone. The only human text for a pair is a one- or two-sentence `narrative_guidance`. The generator then writes two stories from one shared setup, so topic, cast, and scene stay fixed while the target pole changes.

One row is one matched pair:

- `concept_text` expresses the concept pole
- `antagonist_text` expresses the antagonist pole of the **same** setup

Example guidance, for `genuine goal pursuit` ↔ `reward hacking`:

> One agent works earnestly toward the intended objective, while another finds ways to exploit the reward system for credit without truly achieving the goal. The dichotomy is about whether one actually solves the problem or just appears to.

## Scale

| | |
|---|---|
| Narratives | **2,072,000** (1,000 stories per pole per pair) |
| Rows in this dataset | **1,036,000** matched pairs |
| Feature pairs | **1,036** |
| Ontology classes | **148** |
| Languages | English, Mandarin Chinese, Russian, Spanish, German |
| Genres | 10 (see the mapping below) |
| Setups per cell | **10** (`pair_number` 0–9) |
| Generators | `qwen/qwen3-235b-a22b-2507`, `deepseek/deepseek-v4-flash` |

A cell is one pair × one genre × one language × one generator. Each generator covers 1,036 × 10 × 5 = **51,800** cells and **1,036,000** narratives. Both generators together are the 2,072,000 narratives. This dataset stores each setup as one row, so 51,800 × 10 × 2 = **1,036,000** rows.

Same feature in Russian diaries, first setup only, from one generator:

```python
subset = ds.filter(
    lambda r: (
        r["language"] == "Russian"
        and r["genre"] == "diary"
        and r["pair_number"] == 0
        and r["model"] == "qwen/qwen3-235b-a22b-2507"
        and r["concept"] == "genuine goal pursuit"
    )
)
```

`filter` on the full split is slow. For repeated slices, stream or index the parquet shards.

## Columns

| Column | Meaning |
|---|---|
| `id` | Row id |
| `pair_number` | Setup index inside one feature × genre × language × model cell (0–9) |
| `concept` | Pole A label, from the ontology |
| `antagonist` | Pole B label, from the ontology |
| `concept_text` | Story for pole A |
| `antagonist_text` | Story for pole B |
| `narrative_guidance` | Ontology definition of the dichotomy. Not generated by the story model |
| `class_name` | Ontology class |
| `language` | Language of both story bodies |
| `genre` | Writing format |
| `model` | Generator model id |
| `shared_setup` | Shared premise. Written in English even when the stories are not |

## How the stories were written

Each cell is one chat completion: a fixed system message, plus a user message that fills in the pair, class, guidance, genre, and language. Sampling is temperature **1.0** and top-p **0.95**.

The prompt asks for 200–400 words per story (target 300–380). Mandarin uses 600–1,200 characters (target 900–1,100). Protagonist, shared constraints, and the setup sentence are requested in English. The two story bodies are requested in the cell language.

If some `pair_number`s are missing, a follow-up request asks only for those setups. A response may be retried at most ten times when the JSON is incomplete or invalid.

Every request includes the same two demonstrations:

1. a Russian **speech** contrasting universal access with privileged access
2. a Japanese **diary** contrasting causal investigation with blame assignment

Japanese is only a length-and-form demonstration. It is not a corpus language.

The ontology, the generation prompt, and this corpus are released together. The prompt text is the code that builds the system and user messages (genre contracts and the two demonstrations included).

Generation of the full corpus cost about $500.

## Uses

- Difference-in-means vectors: mean residual of `concept_text` minus mean residual of `antagonist_text`
- Held-out language, genre, or generator checks
- Probing whether a direction built on these stories fires on other text

## Limitations

- The stories are synthetic. Fluency and cultural detail vary by language and generator.
- The two poles of a setup are written to be parallel. Some pairs stay closer to a template than others.
- `concept` and `antagonist` are generation targets, not human judgments of the finished text.
- The prompt requests the length band above. Some released stories are shorter or longer than that band; a valid JSON response was kept.
- `news` and `case_study` are fictional formats, not reporting.
- The ontology is a curated set of narratable dichotomies for alignment and interpretability. It is not a complete map of concepts.
